# San Francisco Bike Share Data Analysis

This project analyzes San Francisco bike-share trip data using R to identify usage patterns, peak demand periods, popular stations, and common routes.

The analysis compares bike-share activity across multiple datasets and includes data cleaning, exploratory analysis, statistical summaries, route and station comparisons, and data visualization.

## Objectives

- Clean and organize bike-share trip data
- Compare usage patterns across different time periods
- Identify peak demand periods
- Determine popular stations and routes
- Analyze station connectivity and trip activity
- Create visualizations to communicate key findings

## Tools & Technologies

- R
- R Markdown
- Excel / CSV data
- Data cleaning and transformation
- Exploratory data analysis
- Statistical analysis
- Data visualization

## Analysis Performed

The project includes:

- Cleaning and preparing raw trip data
- Comparing bike-share usage between 2014 and 2015
- Analyzing hourly usage patterns
- Identifying the most frequently used stations
- Identifying popular bike routes
- Comparing station connectivity
- Summarizing yearly differences in bike-share activity
- Creating tables and visualizations to communicate results

## Dataset

The analysis uses San Francisco bike-share trip and station data, including:

- July 2014 bike-share trip data
- July 2015 bike-share trip data
- Station information

The datasets contain more than 10,000 trip records used for exploratory and statistical analysis.

## Project Files

- `bike_share_analysis.Rmd` – main R Markdown analysis
- `bike_share_analysis_report.pdf` – rendered project report
- `data/raw/` – original bike-share datasets
- `data/processed/` – cleaned and summarized datasets
